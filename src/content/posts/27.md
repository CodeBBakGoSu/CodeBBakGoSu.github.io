## 인턴하다가 모르는 코틀린 문법 정리해놓음

#### MAP / SET

Key 와 value 를 가지고 있는 리스트

파이썬의 Dictionary와 똑같은듯?

set -> 순서가 없는 리스트

mutable 이 붙으면 가변형이란 소리임

mutableMap -> 가변형 멥

#### forEach

각 요소로 나누어진 것들에 대해 반복적으로 작업을 수행하는 함수

```
map.forEach{ item -> 사용할 작업 코드 }
```

이런식으로 사용하는듯

#### When

```
When(값){
조건 1 -> 실행코드 
조건 2,
조건 3 -> 조건 2와 3일 때 실행되는 코드
else -> 기본 실행코드 
}
```

이런식으로 ~~값이 들어오면 이거해라 하는 함수

#### .associateBy

리스트나 배열등에서 특정 키를 기준으로 map을 만들때 사용하는것

```
Val map = list.associateBy{it.key(가 될수있는 무언가) }
```

이러며 리스트에 있는 값을 기준으로 키를 가진 map을 만드는것  
이렇게 만드는데 여기서 map의 vlue는 list의 각 요소 자체(it) 이 벨류가 된다!

```kotlin
data class User(val id: Int, val name: String)

val users = listOf(
    User(1, "Alice"),
    User(2, "Bob"),
    User(3, "Charlie")
)

val map = users.associateBy { it.id }
```

이러면 map의 내용은

```bash
    1 = User(1, "Alice"),
    2 = User(2, "Bob"),
    3 = User(3, "Charlie")
}
```

이렇게 된다.

#### .filter

조건의 true인 요소만 남기고, 나머지는 버린다.

```
filtered = list.filter{조건삭}
```

내가 쓴 방식

```python
vla current = levelBatch.filter{ visitedGrouplds.add(it.id) }
```

add는 새로운값이 들어가면 true 아니면 false  
\-> 새로운 애들만 current 에 넣겠다! levelBatch에 있는 애들을 하나씩 visitedGroupIds에 넣어보고

#### .asSequence

```
val result = list
    .filter { ... }      // → 새로운 리스트 생성됨
    .map { ... }         // → 또 새로운 리스트 생성됨
    .toList() 

val result = list
    .asSequence()
    .filter { ... }      // → 조건 만족하면 통과
    .map { ... }         // → 그때 바로 변환
    .toList()            // → 최종 리스트로 반환
```

직관적임 -> 새로운 리스트가 생기는 낭비를 없에는 함수
