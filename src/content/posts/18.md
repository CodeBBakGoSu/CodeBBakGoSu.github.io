# 논문 작성

대학원을 준비 중인 분들, 이미 대학원이신 분들 논문 작성에 어려움이 있을 것이라 생각합니다.  
특이 이공계분들 LaTeX 온라인 편집기랑 붙잡고 구글링 하며 겨우겨우 수식 입력하고, 표 만들고 한 경험이 있을 것이라 생각합니다.

## LaTeX

LaTex 란 아래 코드를 입력하면 랜더링이 될 때

```bash
$B \sin A = A \sin B$
```

![](/images/posts/18/1.png)

이런 식으로 바뀌는 하나의 문법입니다. 

특히 이공계, 통계학등 논문작성할 때 사용됩니다. 

  
하지만 수식이 복잡하거나 표를 만드는 등의 문법이 복잡하여 온라인 편집기나 Overleaf 같은 에디터를 사용합니다.

이마저도 어떤 수식일 때 어떤 문법인지 일일이 구글링 해야 하는 작업이 동반되기 때문에 매우 귀찮습니다.
